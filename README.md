# カウンター

好きな画像と名前を登録して、回数を記録・振り返りできるカウンターアプリです。
iPhone・iPad の Safari で動く Web アプリ（PWA）で、ホーム画面に追加すればアプリのように使えます。

## 主な機能

- 画像が主役のカードをグリッドで一覧表示（画面幅に合わせて列数が変わる）
- ＋−で選んだ日付の回数を記録（クリック音・触覚・アニメーション付き）
- 表示モード：好きな順 / 累計 / 年間 / 月間（ランキングは金・銀・銅メダル、0回は表示しない）
- タグでの絞り込み、名前の部分一致検索（両方同時に使える）
- ドラッグ＆ドロップの並び替え（ホームと同じグリッド）、ピン留め
- 詳細画面：大きな画像、累計、年→月→日の記録、タグ、自由情報欄
- カレンダー：記録がある日はアイコン画像を背景にして回数を表示（全体カレンダーはその日いちばん多かったカウンターの画像）
- 統計グラフ：日別・週間・月間・年間。棒を1回タップすると、期間・回数・前期間比・1日の最高回数を表示
- 設定：アプリ名の変更、週の始まり、外観（ライト/ダーク）、音・触覚のオン/オフ、バックアップの書き出しと復元

## データの保存について

- 記録は**その端末のブラウザの中**（IndexedDB）に保存されます。サーバーには送られません。
- そのため、人ごと・端末ごとに別々の記録になります。
- Safari では「共有 → ホーム画面に追加」してから使うと、データが自動で消されにくくなります。
- 機種変更などに備えて、設定画面からバックアップ（JSON）を書き出せます。

## 公開のしかた（GitHub Pages）

1. GitHub でこのリポジトリを開き、**Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/counter/` で開けるようになる
4. iPhone / iPad の Safari で開き、共有ボタン →「ホーム画面に追加」

## ファイル構成

```
index.html              エントリー
manifest.webmanifest    PWA 設定
sw.js                   オフライン対応（Service Worker）
css/style.css           デザイン（ライト/ダーク）
js/app.js               起動・画面遷移
js/db.js                IndexedDB 保存
js/store.js             状態管理・集計・バックアップ
js/feedback.js          クリック音・触覚
js/ui.js, icons.js      シート・ダイアログ・アイコン
js/views/*.js           各画面（ホーム・並び替え・詳細・カレンダー・統計・設定・編集）
```

ビルド不要のプレーンな HTML / CSS / JavaScript です。

## 更新するとき

アプリのファイルを変更したら、`sw.js` の `VERSION` を上げてください（古いキャッシュが残らないようにするため）。
記録データは IndexedDB に入っているので、アプリを更新しても消えません。
